   (`build_vent_case: obstacles = m['boxes']`); G1 is static pressure at a point in
   free air. UFC 3-340-02 para. 2-15.3.2 (printed p. 64): a front wall sees the normal
   reflected pressure Pr (Fig. 2-15). mu 0.3027 comes from an unreflected load. Mesh the
   wall, or apply Pr, before C10's "survives" is relied on? (C10 passes as committed.)
2. **Disk use is not bounded by `n_snapshots`.** interval0 1.03e-5 s with the
   controller's clamp cannot reach its own 40-60-write band in 30 ms: 748 writes kept
   twice, 173 GiB. The script comment "~6 GB per snapshot, six is plenty" and the
   `1c9b238` message are wrong about the cause. A rerun or the 24-cell Cd point needs
   ~190 GB per run unless the write sizing is fixed first.
3. **Settings virtualization.** The app reads the Store-virtualized settings (sweep on,
   150 GB, keep 10) against a 426.79 GiB corpus; a GUI start deletes one run now. This
   run is safe only while fewer than 10 newer runs exist.
4. **C8 is narrow.** G1's peak is a second rise 8.8 ms after arrival, which C8 does not
   examine; x_hi is 2 m behind G1. The traces are committed.
5. **The negative phase is still open at 30 ms** (-22 to -25 kPa at 30 ms); the SDOF sees
   the record only to 30 ms.
6. **The arrival rule** (first sample above 1.1 x ambient) would give a weaker gauge no
   arrival and no positive-phase impulse. Does not affect this run.
