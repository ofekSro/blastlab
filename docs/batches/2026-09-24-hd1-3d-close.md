## Risks

- **Judging after the numbers.** The thirteen checks are fixed in `_e2e_vent_3d.py`.
  H2 may move them but not edit them; the `git diff -w` criterion enforces that.
  Impulse and arrival are reported with no verdict, because no threshold was
  registered for them before the run.
- **Numerical results.** Nothing in `core/` or `solvers/` changes. The one code edit
  is to a manual `_e2e_` script. Guard: `test_regression.py` stays byte-green, and so
  do the HD1 fast suites listed in H2.
- **The run corpus is the evidence** (§8.2). The corpus sweep can delete the run.
  H1 checks `auto_cleanup` first and copies the evidence out before any reading.
- **A false "not the same case"** can happen if a commit after 19:53 on 2026-09-23
  changed `build_vent_case` / `room` / `vent`. H1 lists those commits. A real
  difference still means a rerun, but the record says why.
- **The C8 reflection check is narrow.** It looks only at gauge 0, only later than
  4 ms after the peak, and only at half the peak. A boundary return that *is* the
  peak, or that arrives before it, would pass. The `x_hi` boundary is 2 m behind the
  target wall and `z_hi` is 3.4 m above the gauge. Report the three full traces so a
  reader can see this. Do not add a check now.
- **Impulse in a 30 ms window.** A vented magazine jet may still be in positive phase
  at 30 ms. `summarize_trace` flags it (`positive_phase_complete`), and an open phase
  must be written as a lower bound.
- **`load_run` on a chamber case** has not been exercised by any test found. The
  fallback in H2 (probes via `reader.py`) covers it and must be declared if used.
- **Evidence provenance.** `hd13_report.html` is dated 2026-09-23 20:06, after the
  run started (19:53:08) but **before it finished** (21:18), so it cannot hold
  results from the finished 3D run. `hd13_vent_jet.mp4` is dated 2026-09-24 08:24
  and `hd13_vent_jet_3d.mp4` 2026-09-24 09:11 (both checked with `Get-Item` by the
  orchestrator); both postdate the run, but the one without `_3d` is not
  necessarily a render of it. The DONE entry and any README in `docs/hd13/` must
  not attribute a file to this run unless H1 ties it there (see clarification 1).
