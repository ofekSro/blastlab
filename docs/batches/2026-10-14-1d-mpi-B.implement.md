### Engineering issues noticed (B5)

- **Timing metric granularity:** `ExecutionTime` is printed to 0.01 s, so a per-step delta
  comes in 10 ms quanta and D6's median lands on round numbers (120 / 40). Recommend the
  mean over the same steps (ET_N / N) as the primary 1D ms/step in future rules. Here both
  pass.
- **Disk per 1D parallel run:** with `adaptive_write=False` this 1 ms run wrote 161 times
  (~0.7 MB each). Without a write budget np 4 keeps every write twice (root + ranks): 217 MB
  vs 111 MB serial. A default-length 1D run on ranks would be several times that. Recommend
  that a follow-up check whether 1D parallel should purge rank copies like the HD1-15 budget
  path. Not touched here.
