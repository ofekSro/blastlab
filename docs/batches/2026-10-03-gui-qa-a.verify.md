### Fixed: F31, the diff tool collapsed different findings (`a99872b`)

`_PATH` let a Windows path's "inner folders" run on to **any** later
`/`. The two texts below both normalised to `folder <path>`, so a changed
finding read as `same`:

- `folder C:\Users\Ofek Rotem\runs\M1 is missing, ratio 1/3`
- `… was written, ratio 1/3`

That is a hole in exactly the tool 10b's triage relies on. The fix: the
inner folders end with the path's own separator (`\1`) and hold no `:`.
The two texts now normalise to `… is missing, ratio #/#` and
`… was written, ratio #/#`. Folders with spaces still normalise
(`C:\Users\Ofek Rotem\…` → `<path>`), and the self-diff is unchanged.
The same commit fixes a 10a leftover in `main()`: `only =[` → `only = [`.
